Finwise → Bloomberg-Parity (Indian Context): 12-Phase Roadmap

Context

A deep peer review of the post-remediation codebase (2026-06-11) graded each module and found:
(a) verified statistical-correctness bugs — NaN beta defaults to 0.0 not 1.0
(PortfolioRiskService.java:160-163), no covariance shrinkage (commons-math3 3.6.1 has no
Ledoit-Wolf class — must hand-implement), Cornish-Fisher guard is NaN-only (:329-335),
realizedVolAnn uses log returns while the risk stack uses simple returns, golden cross is a
state not an event, excluded-symbol weight silently re-normalized;
(b) dead capabilities — StockFundamentals.peerPe/PbPercentile never populated,
MacroSnapshot.fiiNetFlow/diiNetFlow fields exist but unfed;
(c) material tax errors — no pre-31-Jan-2018 LTCG grandfathering, debt MFs taxed under
equity regime;
(d) absent Bloomberg-parity capabilities — multi-factor risk model, GARCH, liquidity-adjusted
VaR, options/IV, yield curve, Monte Carlo goals, MF look-through, Brinson attribution.

User decision: full roadmap, phase-by-phase, each phase shippable with green tests; all
unofficial data feeds included behind circuit breakers. Free data only (Yahoo, NSE, NSDL,
RBI/FBIL, AMFI). Keep the LLM-narrates/Java-computes separation.

Conventions: base package org.amit.finwise; analytics in cfo/service/analytics/, research in
cfo/service/research/, macro in cfo/service/macro/; config cfo.* keys; tests = JUnit+Mockito
with hand-computed golden values (./mvnw -o test; surefire argLine for JDK 25 already set).
Record-evolution rule: exactly ONE RiskDecomposition constructor break (Phase 1); all later
analytics are sibling records (FactorRiskReport, VolForecast, LiquidityReport, ...) aggregated
in CFOAdvisorService.

Phase 2 — Ledoit-Wolf covariance shrinkage (M)

New: cfo/service/analytics/LedoitWolfShrinkage.java — LW 2003 constant-correlation target
(preferred over identity: all-equity portfolio has nonzero mean correlation).
On demeaned returns x_it (use 1/T convention internally, consistently):

  1. r_bar = (2/(N(N-1))) sum_{i<j} s_ij/sqrt(s_ii * s_jj)
  2. Target F: f_ii = s_ii; f_ij = r_bar * sqrt(s_ii * s_jj)
  3. pi_hat = sum_{ij} (1/T) sum_t [x_it * x_jt - s_ij]^2
  4. rho_hat = sum_i pi_ii + sum_{i!=j} (r_bar/2)[sqrt(s_jj/s_ii)*theta_ii,ij
              + sqrt(s_ii/s_jj)*theta_jj,ij],
     theta_kk,ij = (1/T) sum_t [(x_kt^2 - s_kk)(x_it x_jt - s_ij)]
  5. gamma_hat = sum_{ij}(f_ij - s_ij)^2;
     delta = clamp(kappa_hat/T, 0, 1) with kappa_hat = (pi_hat - rho_hat)/gamma_hat
  6. Sigma_LW = delta*F + (1-delta)*S

Integration: CovarianceEngine.shrunkCovariance() -> ShrinkageResult(sigma, delta).
PortfolioRiskService uses Sigma_LW for vol/VaR/MCR/CCR when N >= 3 and
cfo.risk.shrinkage-enabled=true (default); populates shrinkageIntensity.
Betas stay pairwise (shrinkage would bias them).
PSD guard: EigenDecomposition (in commons-math3); clip eigenvalues < -1e-10 to 0 and
reconstruct.

Tests: LedoitWolfShrinkageTest — 3-asset T=10 fixture with offline-computed goldens
(F entries, delta, Sigma_LW entries to 1e-9); delta in [0,1] property;
large-T i.i.d. -> delta approx 0; min-eigenvalue >= 0.

Phase 9 — GARCH(1,1) + liquidity-adjusted VaR (L)

- 9a. cfo/service/analytics/GarchService.java:
  sigma2_t = omega + alpha * eps2_{t-1} + beta * sigma2_{t-1};
  log-likelihood -0.5 * sum[ln(2*pi) + ln(sigma2_t) + eps2_t/sigma2_t],
  seed sigma2_1 = sample variance.
  Optimize with SimplexOptimizer + NelderMeadSimplex over transformed params:
  omega=exp(theta1), p=alpha+beta=sigmoid(theta2)*0.9999, alpha=p*sigmoid(theta3).
  Init alpha=0.05 beta=0.90.
  Fallback to EWMA (P1g lambdas) when T<250, non-convergence, alpha+beta>=0.999,
  or unconditional vol >3x sample — always with note.
  Forecast: sigma2_{t+h} = sigma2_LR + (alpha+beta)^{h-1}*(sigma2_{t+1} - sigma2_LR),
  sigma2_LR = omega/(1-alpha-beta); 10-day vol = sqrt(sum sigma2_{t+h}).
  New record cfo/model/VolForecast.java; PortfolioRiskService.forwardRisk() fits on
  the portfolio series (one fit).
  Test: 3000 simulated obs, (omega,alpha,beta)=(2e-6,0.08,0.90), fixed seed ->
  recover alpha+-0.04 beta+-0.05; fallback triggers.

- 9b. cfo/service/analytics/LiquidityService.java:
  Corwin-Schultz 2012 spread from H/L (fields exist on StockPriceHistory):
  beta_cs = [ln(H_t/L_t)]^2 + [ln(H_{t+1}/L_{t+1})]^2;
  gamma_cs = [ln(H_2d/L_2d)]^2;
  alpha_cs = (sqrt(2*beta_cs) - sqrt(beta_cs))/(3-2*sqrt(2))
             - sqrt(gamma_cs/(3-2*sqrt(2)));
  S = 2*(exp(alpha_cs)-1)/(1+exp(alpha_cs));
  floor negatives at 0 before 60d averaging; overnight-gap adjustment.
  DTL_i = shares_i / (0.20 * ADV20_i).
  LVaR = VaR95 + 0.5 * sum(S_i * w_i * V) (+ stressed x2 variant).
  New record cfo/model/LiquidityReport.java (spreads bps, DTL, weightLiquidatableIn1d/5d,
  lvar95, illiquid flags DTL>5). Hand-computed 3-day CS fixture to 1e-8.
